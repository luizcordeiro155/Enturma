# Importação acadêmica

Nenhum catálogo de produção foi incluído. Reúna documentos oficiais da instituição, campus, curso e versão específica da matriz curricular. Registre a URL e data da conferência. Importe em ordem hierárquica por `/api/v1/admin/academics/import` ou pela interface `/admin`.

Status PENDING_VERIFICATION não aparece no onboarding. Não promova para VERIFIED só para preencher a tela. A API valida estrutura e datas; a autenticidade da fonte requer trabalho administrativo.

O formato JSON está em docs/API.md. Importação CSV e integrações oficiais automatizadas ainda não foram implementadas.
